# Нормативные документы для проектирования инженерных систем зданий

Справочный репозиторий по действующим нормам России и Казахстана: ГОСТ, СНиП, СП, СН РК, СП РК, НТП РК, СТ РК.
Охват: все основные разделы проектной документации — ОВ, ВК, пожарная безопасность, сигнализация,
видеонаблюдение, СКУД, связь, автоматизация, электроснабжение, газоснабжение, наружные сети,
основания и изыскания, конструкции, инженерная защита, доступность, АР и оформление документации.
Нужен для быстрой проверки, какой документ действует, в какой редакции и в какой стране применяется.

Каталог не заменяет официальный текст. Он отвечает на вопросы «что действует» и «чем заменено», а сами нормы смотрите в первоисточнике по ссылке из карточки.

## Что внутри

```
catalog/
  ru/       карточки документов, действующих в России
  kz/       карточки документов, действующих в Казахстане
  both/     межгосударственные документы, применяемые в обеих странах
docs/       методика и правила ведения каталога
scripts/    проверка карточек, сборка каталога, сверка статусов, поиск
_schema.md  описание полей карточки
```

Один документ — один YAML-файл. Каталог `catalog/README.md` и машинный индекс `catalog/index.json` собираются из карточек, руками их не правят.

## Как пользоваться

Найти норму по номеру или теме:

```bash
python3 scripts/find.py 60.13330
python3 scripts/find.py "отопление" --jurisdiction kz
python3 scripts/find.py --scope vk --jurisdiction ru
```

По умолчанию заменённые документы скрыты. Показать всё — флаг `--all`.

Проверить, что каталог не сломан:

```bash
python3 scripts/validate.py
```

Проверить, что ссылки в карточках живые:

```bash
python3 scripts/validate.py --links
```

Сверить статусы с официальными реестрами:

```bash
python3 scripts/check_status.py --jurisdiction ru
```

Пересобрать каталог после правки карточек:

```bash
python3 scripts/build_index.py
```

Зависимости: Python 3.10+ и `PyYAML` (`pip install -r requirements.txt`).

## Разделение по юрисдикциям

| Каталог | Что попадает |
| --- | --- |
| `catalog/ru/` | Документы, действующие только в РФ: СП, ГОСТ Р |
| `catalog/kz/` | Документы, действующие только в РК: СН РК, СП РК, НТП РК |
| `catalog/both/` | Межгосударственные ГОСТ, применяемые в обеих странах |

Правило простое: если документ подтверждён в реестрах обеих стран — он в `both`. Если только в одной — в её каталоге. Поле `jurisdiction` в карточке обязано совпадать с каталогом, это проверяет валидатор.

## Статусы

| Статус | Значение |
| --- | --- |
| `действует` | Применяется |
| `частично_действует` | Действует не полностью |
| `заменён` | Отменён с заменой, есть `superseded_by` |
| `отменён` | Отменён без замены |
| `не_проверено` | Статус не сверен с реестром, в карточке стоит `todo: true` |

Статус ставится только по официальному источнику. Догадки в каталоге запрещены: сомнительный статус помечается `не_проверено`, а не «наверное действует».

## Источники

| Страна | Источник | Что даёт |
| --- | --- | --- |
| РФ | [docs.cntd.ru](https://docs.cntd.ru) | Текст, дата введения, изменения |
| РФ | [files.stroyinf.ru](https://files.stroyinf.ru) | Реестр со статусами «действует / не подлежит применению» |
| РК | [prg.kz](https://prg.kz) | Карточка «Информация о документе»: статус, дата введения |
| РК | [ksm.kz](https://new-shop.ksm.kz) | КазСтандарт: статус ГОСТ |
| РК | [online.zakon.kz](https://online.zakon.kz) | Приказы о введении в действие |

Ссылка на каждый использованный источник лежит в поле `sources` соответствующей карточки.

## Как добавить документ

1. Возьмите официальный статус из реестра, а не из поисковой выдачи.
2. Создайте YAML в нужном каталоге по образцу `_schema.md`.
3. Запустите `python3 scripts/validate.py` и `python3 scripts/build_index.py`.
4. Проверьте, что в `catalog/README.md` появилась строка с верной ссылкой.

## Ограничения

- Тексты документов не хранятся: только реквизиты и ссылки.
- Дата сверки статуса — поле `updated` в карточке. Если оно старое, статус мог измениться.
- Каталог покрывает инженерные разделы и смежные документы, а не всю нормативную базу строительства.
- По охранной сигнализации, СКУД и видеонаблюдению в РФ действуют в основном ГОСТ Р на оборудование:
  нормативных требований к размещению этих систем в зданиях меньше, чем для пожарной сигнализации.
