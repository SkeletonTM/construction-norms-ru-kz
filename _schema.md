# Схема карточки документа

Каждый документ — один YAML-файл в `catalog/<юрисдикция>/`.
Имя файла: `<вид>-<номер>.yaml`, например `sp-60.13330.2020.yaml`, `gost-3262-75.yaml`.

## Юрисдикции

| Каталог | Что кладём |
| --- | --- |
| `catalog/ru/` | Документы, действующие только в РФ |
| `catalog/kz/` | Документы, действующие только в РК |
| `catalog/both/` | Документы, применимые в обеих странах (межгосударственные ГОСТ, СНиП СССР и т. п.) |

## Поля

### Обязательные

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | строка | Уникальный идентификатор, совпадает с именем файла без `.yaml` |
| `kind` | перечисление | `ГОСТ`, `ГОСТ Р`, `СНиП`, `СП`, `СН РК`, `СП РК`, `НТП РК`, `СТ РК` |
| `number` | строка | Номер без вида: `60.13330.2020`, `3262-75`, `4.02-101-2012` |
| `title` | строка | Название на русском, как в официальном издании |
| `jurisdiction` | перечисление | `ru`, `kz`, `both` — должен совпадать с каталогом файла |
| `status` | перечисление | см. ниже |
| `scope` | список | Разделы проектирования, см. таблицу ниже |
| `sources` | список | Не менее одной записи `{url, kind}` |
| `updated` | дата | `YYYY-MM-DD`, дата последней сверки карточки |

| Код | Раздел |
| --- | --- |

| `skud` | Контроль и управление доступом |
| `ss` | Системы связи, электросвязь, оповещение, радиовещание |
| `avtomatika` | Автоматизация и диспетчеризация инженерных систем |
| `elektro` | Электроснабжение и электроустановки зданий |

| `gaz` | Газоснабжение и газораспределение |

В одном документе может быть несколько разделов: СП 7.13130.2013 относится и к `ov`, и к `pozh`.

### Статусы

| Значение | Смысл |
| --- | --- |
| `действует` | Действующий, применяется |
| `частично_действует` | Действует не полностью или с ограничением области применения |
| `заменён` | Заменён новым документом, есть `superseded_by` |
| `отменён` | Отменён без замены |
| `не_проверено` | Статус не сверен с официальным источником, обязателен `todo: true` |

### Необязательные

| Поле | Тип | Описание |
| --- | --- | --- |
| `title_en` | строка | Название на английском/казахском, если есть в источнике |
| `edition` | строка | Редакция и учтённые изменения: «с Изменениями № 1-6» |
| `introduced` | дата | Дата введения в действие |
| `superseded_by` | строка | `id` карточки-замены. Обязательно при `status: заменён` |
| `supersedes` | список | `id` карточек, которые заменены этим документом |
| `applies_in_kz` | булево | Для `catalog/both/`: подтверждено ли применение в РК |
| `enacted_by` | строка | Приказ/постановление, вводящее документ в действие |
| `notes` | строка | Одно-два предложения по существу: чем полезен, на что смотреть |
| `todo` | булево | `true` — карточка неполная, требует проверки. Обязательно при `status: не_проверено` |
| `checked_by` | строка | Кто сверял статус (агент, ФИО) |
| `source_checked` | дата | Дата, на которую статус подтверждён источником |

## Правила

1. `status` ставится только по официальному источнику: `prg.kz` (Параграф) для РК, `docs.cntd.ru` + `files.stroyinf.ru` для РФ, `ksm.kz` для ГОСТ в РК.
2. Если источник не подтверждает статус — `status: не_проверено` и `todo: true`. Догадки запрещены.
3. `superseded_by` и `supersedes` должны ссылаться на существующие `id` и быть взаимно согласованы.
4. `jurisdiction` обязан совпадать с каталогом: `catalog/ru/` → `ru`.
5. Ссылки в `sources` обязаны отвечать HTTP 200 (проверяется скриптом по флагу `--links`).

## Пример

```yaml
id: sp-60.13330.2020
kind: СП
number: "60.13330.2020"
title: Отопление, вентиляция и кондиционирование воздуха
jurisdiction: ru
status: действует
scope: [ov]
edition: с Поправкой, с Изменениями № 1-6
introduced: 2021-07-01
supersedes: [sp-60.13330.2016]
enacted_by: приказ Минстроя России от 30.12.2020 № 921/пр
notes: Основной документ по ОВ. Проверять актуальную редакцию перед выдачей.
updated: 2026-11-25
sources:
  - url: https://docs.cntd.ru/document/573697256
    kind: текст
  - url: https://files.stroyinf.ru/cgi-bin/ecat/ecat.fcgi
    kind: статус
```

## Типы источников (`sources[].kind`)

| Значение | Что это |
| --- | --- |
| `текст` | Полный текст или карточка документа |
| `статус` | Реестр/каталог, подтверждающий статус |
| `магазин` | Платный магазин стандартов (КазСтандарт) |
| `приказ` | Правовой акт о введении в действие |
