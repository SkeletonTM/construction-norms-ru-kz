# Контрольные примеры по применимости изделий ВК

Эти примеры - напоминания для проектировщика, а не карточки товаров. Каталог хранит нормативные документы; он не подтверждает эквивалентность изделий и не доказывает производство в РК.

## Общие правила

- Несовпадение ГОСТ в спецификации не означает, что стандарт заменён. Сначала проверьте паспорт изделия и фактическое соединение.
- Код АГСК, номер ГОСТ, наличие продажи в РК и бренд не доказывают казахстанское происхождение. Происхождение хранится отдельно, по документам изготовителя и поставки.
- Нормативная актуальность документа и пригодность конкретного изделия - разные вопросы.

## контрольные случаи

| Код / случай | Что проверить | Чего не делать |
| --- | --- | --- |
| NRV EF, код 242-307-0603 | Паспорт изделия и тип соединения | Считать несовпадение ГОСТ заменой стандарта |
| ВК2/К1, коды 241-208-4501, 241-209-3503, 241-208-4403 | Материал ПЭ/ПП, раструб, уплотнительное кольцо | Молча заменять материал |
| Изоляция 234-305-0317 | Фактический диаметр и посадку, пожарные показатели | Считать Ø108 взаимозаменяемым с Ø110 |
| Гофра 241-207-0106 | Канализационное назначение, длина, единица измерения | Приравнивать гофру с зондом к обычной; «шт» к «м» |
| Счётчик 244-301-0701 | Исходные требования заказчика, радиомодуль, класс C и Qn 2,5 | Выводить их из факта импульсного выхода |
| Унитаз 244-101-0301-0001 | Комплектация гибкой подводкой | Считать подводку частью комплекта без подтверждения |
| Душевой смеситель 244-104-0507 | Наличие гигиенической лейки | Предполагать её в комплекте |
